A one-image front page of Saturday 21 November 2026: the Gulf flashpoint (Iran hits US bases, Trump warns Tehran), the Shenzhen summit, COP31's fossil-fuel deadlock, Peru's magnitude 6.9 quake, the AI sell-off, and GTA VI's record $2.36B launch. The poster is drawn programmatically by `render_artwork.py` (Pillow) into `artwork.png`; `main.py` hands those exact bytes to the judge on every run.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
